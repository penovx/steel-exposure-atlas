PRIVACY

Minimal data collection by design.

Steel Exposure Atlas is a static public-data demonstrator. The application itself does not require an account and does not ask visitors to submit personal information.

What the atlas does not collect

  • No user accounts, sign-in or profiles.
  • No forms, file uploads or visitor-submitted content.
  • No behavioural analytics or advertising pixels.
  • No runtime AI service processing visitor prompts or identifiers.
  • No external fonts, remote map tiles or embedded third-party media.
  • The atlas code does not set tracking cookies or use browser storage for visitor profiling.

Hosting

The intended public release is hosted with GitHub Pages. GitHub documents that GitHub Pages is a static-site hosting service and that visitor IP addresses are logged and stored for security purposes when a Pages site is visited.

That hosting-level processing is performed by GitHub, not by Steel Exposure Atlas application code. GitHub's own privacy terms govern GitHub's processing.

External source links

The atlas contains links to official data publishers and source documents, including Global Energy Monitor, the European Commission, EUR-Lex and OFAC. Opening those links leaves the atlas site. The destination site's own privacy terms then apply.

Local runtime data

The interactive atlas reads reviewed data files from the same site origin. These files contain public industrial, regulatory and cartographic information used by the project. They are not visitor datasets.

Changes

This notice must be reviewed before publication if the project adds analytics, user accounts, uploads, runtime AI processing, third-party embeds, remote application services or a different hosting model.
