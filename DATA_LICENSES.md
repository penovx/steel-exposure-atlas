# Data licences and reuse status

This file records third-party datasets that are actually included in published project outputs.

No third-party dataset is currently bundled or redistributed by this repository.

A dataset may be added here only after the specific version or download package has been reviewed for the intended use.

For each published dataset, record:

- source and publisher
- dataset name and version/date
- source URL
- retrieval date
- licence or applicable terms
- whether modification is permitted
- whether redistribution of the original or derived data is permitted
- required attribution text
- material restrictions or caveats
- files or fields used by this project
- transformations applied

Candidate sources under review belong in `data/source-registry.json`; appearing there does not mean they are approved for redistribution.
